# PROTOTYPE — 朝30分の基本学習ループ

> 使い捨ての検討用です。mainへ取り込む完成品ではありません。

## この試作品で答える問い

準備済みの学習セットを開いた後、`遅延想起 → 狭いインプット → 資料なしの説明 → 診断・変形問題 → 根拠確認と再説明` の順に進めると、30分以内に「思い出す・理由を説明する・条件変更へ適用する・誤りを直す」を残せるか。過去問の答えを覚えている場合や説明できない場合にも、手順が破綻しないか。

研究から直接決まる最適配分ではなく、Issue #4で判断するための仮説である。

## 実行

```bash
python3 prototypes/issue-4-morning-loop/run.py
```

各工程で成功・空振りを選び、診断問題では「答えを覚えていた」ケースも試す。毎回、経過時間、現在工程、得られたアウトプット、未解決事項が画面に表示される。
