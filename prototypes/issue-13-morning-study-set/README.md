# PROTOTYPE — 毎朝の準備済み学習セット

> 使い捨ての検討用です。mainへ取り込む完成品ではありません。

## この試作品で答える問い

前回の明示的な学習結果、再学習・翌日再テスト・期限超過・当日期限のキュー、教材の利用可否、曜日を入力にすれば、朝30分、昼5分、任意の通勤、最低5分へ一件ずつ機械的に割り当てられるか。前回結果が未記録、教材が読めない、問題生成に失敗した場合にも、進捗を推測せず新規学習を止め、答えを含まない安全な再開セットへ縮退できるかを確認する。

教材の例は `2026_構造_文章問題.pdf` の「K6. 鉄骨構造」18〜20ページ（PDF 193〜195ページ）の位置情報と概念名だけを使う。教材本文、解答、個人の学習記録はこの試作品へ保存しない。

## 実行

```bash
python3 prototypes/issue-13-morning-study-set/run.py
```

数字キーで九つの境界シナリオを切り替える。画面には入力状態、割当て理由、朝・昼・通勤・最低5分のセット、進捗を進めてよいかが表示される。

## 見るポイント

- 2回連続不合格、翌日再テスト、期限超過がある間は新規学習を増やさないか
- 当日期限の短い再テストだけなら、朝は新規、昼は再テストへ分けられるか
- 前回結果を記録していない状態を、完了と推測して次へ進めていないか
- 状態ファイルが消えても、前回セットが残っていれば初日に戻していないか
- 教材不在または生成失敗を、学習者の欠席・不合格にしていないか
- 休日に昼休みと通勤の必須項目を作っていないか
- 同じ日に自動化が再実行されても、新しいセットや進捗を重複生成していないか
- すべての出力が問題だけを示し、想定解や教材本文を先取りしていないか

## 試行後の結論

九つの境界シナリオを順に操作し、次を確認した。

- 再学習、翌日再テスト、期限超過、中断は、新しい原理より前に一件ずつ割り当てられた
- 当日期限の3分または5分の再テストだけなら、平日は朝の新規一件と昼の再テストへ分けられた
- 休日は昼と通勤を空にし、期限項目を朝の一件へ移せた
- 前回結果未記録、状態ファイル消失、同日重複実行のいずれでも、完了や次段階を推測しなかった
- 教材不在時は根拠確認を要求せず、生成失敗時は既知概念の5分想起へ縮退し、どちらも正式な進捗に数えなかった
- 画面へ表示するのは課題、参照位置、終了条件だけで、想定解と教材本文は出さなかった

最初の試行では、休日の期限項目が朝へ移らない、教材不在なのに根拠確認を指示する、状態ファイル消失を初回と誤認し得る三点が見つかった。修正後の再試行で解消した。

したがって、毎朝の自動準備は、**明示されたローカル状態だけを正本とし、一日一セット、各枠一件、失敗時は進捗を止めた5分フォールバック**とする。試作品本体はmainへ取り込まず、この結論だけを正式な運用仕様へ移す。
