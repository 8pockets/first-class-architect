# PROTOTYPE — 過去問暗記を見抜く転移テスト

> 使い捨ての検討用です。mainへ取り込む完成品ではありません。

## この試作品で答える問い

元の過去問に正答できても、同じ原理から作った「単一条件変更・反例・概念識別・初見統合」へ段階的に答えさせれば、答えの記憶と条件が変わっても使える理解を区別できるか。各回答を `結論・理由・効いている条件` の3点で判定し、ヒントを使った回答を合格扱いしない規則が妥当かを確かめる。

問題例は主教材 `2026_構造_文章問題.pdf` の「K6. 鉄骨構造」18〜20ページ（PDF 193〜195ページ）を根拠に作成している。

4問を同じ朝にすべて解く運用案ではない。問題型と判定状態を比較するための試作品である。

## 実行

```bash
python3 prototypes/issue-6-transfer-test/run.py
```

回答を入力した後に教材上の確認点が表示される。3つの判定項目を手動で切り替え、次へ進むと、現在どの段階まで確認できたかが表示される。
