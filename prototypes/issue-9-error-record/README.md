# PROTOTYPE — 誤答を次の学習へ変える最小記録

> 使い捨ての検討用です。mainへ取り込む完成品ではありません。

## この試作品で答える問い

有効な問題への未合格を、`知識欠落・因果誤解・条件誤認・想起失敗・転移失敗・処理ミス` の主原因一つに分類し、`誤り → 正しい根拠` の差分を一文だけ残せば、次のインプット／アウトプットを自動的に一件へ絞れるか。証拠が足りない場合は一時的に `要再診断` とし、問題側の条件不足などは `問題無効` として学習者の失敗から分離する状態モデルも確認する。

構造の例は、既に決めた三点説明・転移テストの境界を操作するための検討用であり、この試作品自体を正解根拠や学習教材にはしない。

## 実行

```bash
python3 prototypes/issue-9-error-record/run.py
```

各ケースで原因を一つ選び、`誤り → 正しい根拠` を一文入力する。画面には、分類から自動生成した当日の訂正行動、次回の出力、学習者の失敗に数えるかが表示される。

## 見るポイント

- 一つの主原因で次の一件を決め、証拠不足時だけ要再診断へ送れるか
- 知識欠落と想起失敗を、根拠確認後の説明可否で区別できるか
- 条件誤認と転移失敗を、原理選択と未知条件への適用のどちらで崩れたかにより区別できるか
- 処理ミスを概念の再学習へ誤って戻していないか
- 問題無効を誤答履歴と再テスト失敗数へ入れていないか
