# 2週間の構造パイロット検証基準

決定日: 2026-08-04

根拠: [2週間の検証基準と中止・修正条件を決める](https://github.com/8pockets/first-class-architect/issues/10)

## 決定

2週間の構造パイロットでは、過去問得点や勉強時間の合計ではなく、**理解、転移、保持、継続**を別々に測る。四つすべてが基準を満たした場合だけ方法採用とし、一つでも満たさなければ、証拠不足・方法修正・方法中止のどれかへ分ける。

この基準での方法採用は、鉄骨部材の座屈と塑性変形能力について、同じ方法を構造内で次の検証へ進めてよいという意味に限る。一級建築士試験への有効性確定や他科目への展開を意味しない。

数値基準は学習科学から直接得られた合格点ではなく、短いパイロットで都合のよい解釈を避けるための事前ルールである。結果を見て閾値を変更しない。

## 実行期間と判定日

実行期間は最初の学習日を0日目とする14日間とし、14日目以降は新しい原理を増やさない。ただし、後半に学んだ項目や再テストの延期により、保持の判定は14日目に完了しない。

最初に選んだ二つの保持対象が14日後の初見統合問題まで到達してから最終判定する。したがって、**学習方法を実行する期間は14日、結果を閉じる日は最後の保持対象の実際の判定日**とする。14日経過だけで保持成功・失敗を決めない。

予定された復習間隔によって14日目より後に判定することは、判定保留による延長には数えない。最大7日延長は、外的事情で本来の証拠を実施できなかった場合だけに使う。

## 開始前に固定するもの

結果を見て対象を選び直さないよう、開始前に次を記録する。

- 14日間の開始日と終了日
- 予定する平日の学習機会。通常は10日、最低8日以上ある期間を選ぶ
- 異なる原理単位を四つ。パイロット範囲の四領域のうち、少なくとも三領域を含める
- 最初に学ぶ二つを保持対象として指定する
- 六つの転移テスト枠と問題型
- 健康、仕事、家庭のため学習しないことを事前に決めた日

事前に除外していない予定日を、実施できなかった後から分母から外さない。病気や突発業務は欠席として残し、判定保留の理由にできる。

## 評価可能になる最低証拠

次のすべてが揃うまで、方法を採用・修正・中止と判定しない。

| 領域 | 最低証拠 |
|---|---|
| 理解 | 異なる四原理について、初回学習と訂正版の三点説明を記録 |
| 転移 | 有効な転移テスト六問。少なくとも三種類を含み、初見統合を一問含む |
| 保持 | 事前指定した二原理について、7日後と14日後の有効な再テスト結果、または途中段階での2回連続未合格 |
| 継続 | 事前に定めた最低8回、通常10回の平日学習機会について、主学習・縮退・欠席を記録 |

転移テストの問題無効は分母へ入れない。問題無効により六問へ達しない場合は、学習者の証拠不足ではなく作問方法の修正対象とする。

病気、忌引き、突発的な業務など、方法と無関係な理由で最低証拠が不足した場合は判定保留とする。新しい原理を追加せず、不足した証拠だけを最大7日間延長して集める。最大延長後も、方法自体の重さや作問不備で証拠が揃わない場合は方法修正へ移る。

## 四つの成功基準

### 1. 理解

四原理のうち三原理以上で、30分を延長せず、根拠確認後に資料を閉じて次の三点を正しく再生成できること。

1. 結論
2. 原理に基づく理由
3. 結論に効いている条件

訂正版を教材から書き写した場合や、ChatGPTの模範文を再入力した場合は成功に数えない。

### 2. 転移

有効な六問のうち四問以上を、最初の回答または翌日の別問題による再テストまでに、資料・解説・ヒントなしで合格すること。さらに、初見統合問題を少なくとも一問合格すること。

同じ過去問への再正答、単なる数値置換、問題無効は六問に含めない。結論だけでなく、理由と効いている条件の三点すべてを必要とする。

14日後の初見統合問題は、六問の転移テストの一問と保持対象の最終テストを兼ねてよい。同じ回答を転移テスト二問分として重複計上しない。

### 3. 保持

事前指定した二原理について、次をすべて満たすこと。

- 二原理とも7日後の段階を、最初の回答または翌日の別問題までに合格
- 二原理とも14日後の初見統合段階を、最初の回答または翌日の別問題までに合格
- 少なくとも一原理は、14日後の最初の回答で合格

14日後の直前に教材を読み直した場合、ヒントを使った場合、同じ問題を再利用した場合は保持成功に数えない。

保持対象が同じ段階で2回連続して未合格になった場合、その原理は今回のパイロットでは保持未達と確定する。通常運用として再学習と新しい0日目へ戻るが、その後の合格で今回の未達を上書きしない。再学習後の結果は次の検証データにする。

### 4. 継続

事前に定めた平日の学習機会について、次をすべて満たすこと。

- 80%以上の日で主学習または縮退学習を一件実施
- 主学習枠を六回以上実施
- 30分を超過した主学習が一回以下
- 夜の埋め合わせを一度も行わない
- 欠席または中断後、次の二回の予定機会以内に主学習または縮退学習へ戻る
- 運転中、歩行中、混雑時など安全でない通勤学習を一度も行わない

縮退学習を主学習と同じ進捗に数えない。連続日数だけでも成功としない。

この継続基準は、現在の生活で運用できるかを測るものであり、14日間で習慣が形成されたことを意味しない。

## 判定用の集計

日々の記録へ新しい長文を追加せず、既に決めた運用記録、三点説明、転移・間隔再テスト、誤答記録から次だけを集計する。

```text
実行: 予定__日 / 実施__日 / 主学習__回 / 超過__回 / 夜の埋め合わせ__回
理解: 三点再生成 __ / 4原理
転移: 2回以内の合格 __ / 6問 / 初見統合 合格・未合格 / 問題無効__問
保持: 7日後 __ / 2原理 / 14日後初回 __ / 2原理 / 14日後2回以内 __ / 2原理
再開: 欠席・中断__回 / 二機会以内の再開__回
誤答: 主原因ごとの件数
```

得点率、勉強時間、読んだページ数、過去問周回数は、このパイロットの採用判定には使わない。

## 判定順

最終判定は次の順で行い、先に該当した状態を採用する。

1. 生活・安全の即時中止条件があるか
2. 最低証拠が揃い、評価可能か
3. 学習効果の無信号に該当しないか
4. 問題無効が二問以上発生していないか
5. 理解基準を満たすか
6. 転移基準を満たすか
7. 保持基準を満たすか
8. 継続基準を満たすか

問題無効が二問未満で、四基準をすべて満たした場合だけ方法採用とする。基準未達が複数あっても、修正するのは判定順で最初に未達となった領域だけにする。上流の理解が崩れている状態で、復習間隔や習慣だけを同時に変えない。

## 方法修正

最低証拠が揃い、即時中止条件がなく、一つ以上の基準が未達なら方法修正とする。次の対応から一つだけ選び、7日間の修正実行と必要な遅延テストを一度だけ行う。

| 最初の未達 | 一変数の修正対象 |
|---|---|
| 理解 | 一回の入力範囲、前提知識、解答例の量のいずれか一つ |
| 転移 | 条件変更の作り方、問題難度、概念識別の組合せのいずれか一つ |
| 保持 | 次の復習間隔、想起手掛かり、再学習単位のいずれか一つ |
| 継続 | 開始合図、準備済みセット、時間枠割当てのいずれか一つ |

問題無効が二問以上発生した場合は、学習者の転移成績を下げず、作問テンプレートを修正する。同じ主原因の誤答記録が三件以上あれば、その原因を修正対象選択の根拠にする。

修正中も合格条件を緩めず、結論・理由・条件の三点、資料・ヒントなし、制限時間を維持する。

## 方法中止

方法中止は受験勉強の中止ではなく、現在の30分ループ、問題生成、復習、記録を組み合わせた方法を終了し、別の設計へ戻すことである。

次のいずれかで方法中止とする。

### 即時中止

- 学習の継続が睡眠不足、体調悪化、仕事上の安全低下を生じさせる
- 夜の家族時間を恒常的に削らなければ運用できない
- 安全でない通勤中の操作を前提にしなければ期限を守れない

即時中止条件は14日目を待たず、その活動または現在の運用を止める。

### 学習効果の無信号

最低証拠が揃った状態で、次の二つが同時に起きた場合は、部分修正を続けず現在の方法を中止する。

- 六問の有効な転移テストで、二回以内の合格が0問
- 二つの保持対象で、7日後の合格が0原理

### 修正後も同じ基準が未達

一変数だけを変えた修正検証を一度行っても、最初に未達だった領域が同じ成功基準へ到達しなければ現在の方法を中止する。結果に合わせて修正を重ね続けない。

## 境界シナリオ

| 結果 | 判定 |
|---|---|
| 四基準をすべて満たした | 方法採用。構造内の次の検証へ進む |
| 理解は合格、転移が3/6 | 転移を方法修正。教材の再読量は増やさない |
| 学習結果は合格、実施が6/10で夜の埋め合わせあり | 継続を方法修正。合格条件は下げない |
| 病気で四日欠席し、保持対象が一つしか測れない | 判定保留。不足証拠だけ最大7日延長 |
| 問題無効が二問あり六問へ達しない | 作問方法を修正。学習者の失敗にはしない |
| 転移0/6かつ7日保持0/2 | 方法中止。別の学習設計へ戻る |

## 結果を残す場所

個々の学習記録はローカルに保ち、GitHubには上の集計、採用・修正・保留・中止の判定、判定根拠だけをパイロット結果として残す。原理台帳の自作2択問題を除き、教材の問題文、解説全文、個人の詳細な学習履歴はGitHubへ置かない。
