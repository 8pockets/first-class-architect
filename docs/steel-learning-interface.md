# 鉄骨構造ページの小分け学習

2026-10-15の改善と2026-10-17の1ページ表示への変更。既存の311カード、骨格47／標準149／発展115、問題ID・番号、答えの個別／一括開閉、ブラウザ内の回答履歴を維持する。

## 開始と再開

- 初期の範囲は骨格。標準を選ぶと骨格＋標準、発展を選ぶと全層が対象になる。一覧の層別フィルターは従来通り独立して利用できる。
- 「今日の10問」は当日未曝露の重点復習、要復習から最大5問、その後に未回答を既存の導入順で選ぶ。合計最大10問。不足分を同日練習や重複で埋めない。
- 「今日の復習」は当日未曝露の復習のみ最大10問。重点復習を先にする。
- 選んだ問題はセットの順序で1ページに縦並びにする。「次の問題」「前の問題」での切り替えはなく、スクロールしながら好きな順で答えられる。各カードにセット内の番号・復習／新規・分野を添える。
- 回答直後にはカードを移動・非表示にせず、スクロール位置も自動で次問へ動かさない。全問に答えると結果を表示する。「今回の学習を終える」から未回答があっても終了できる。
- セット内でも答えの個別／一括開閉ができる。開いた答えは従来通り閲覧履歴として扱い、回答済みにはしない。
- 学習セットの順序・回答済みIDは回答イベントとは別に端末内保存する。日をまたいでも「続きから」は同じセット全体を表示し、最初の未回答へ戻る。以前の1問ずつ表示していた保存セットも引き継ぐ。
- 選択範囲を一周すると次の層を案内する。正解率や復習解除を進級条件にせず、層選択はロックしない。
- 「前提を確認」ではセット全体を保ったまま対象へ移動する。セット外の前提カードは補助として表示し、元の問題へ戻る操作を用意する。補助カードはセットの回答数に含めない。
- 2026-10-18のレイアウト整理では、成績・小項目の現在地、使い方・履歴管理、一覧・検索を折りたたみにした。学習中は共通ヘッダーなどを畳み、進捗・一括開閉・「その他」を上部の小さな固定バーに表示する。終了・一覧への移動は「その他」から操作する。
- Google検索は正解・解説の中に配置し、開いたときに表示する。内容の種類（原理・規定・識別）・回答履歴・出典は「補助情報」にまとめ、カード上部には骨格・標準・発展を表示する。問題・選択肢・正解・解説と、回答・復習の判定は変更しない。補助情報を開くだけでは答えを見た扱いにしないが、回答履歴や外部解説を確認した場合は従来通り扱う。
- 2026-10-25にカード下部の操作を1行に集約。正解・解説は目、補助情報はi、解き直しは回転矢印のアイコンとし、44pxの操作領域、ツールチップ、読み上げ用の操作名を維持する。開閉はネイティブのdetails/summaryを用い、複数カード・解説と補助情報を同時に開ける。問題・選択肢・解説の内容、改訂情報、履歴判定、印刷の問題部分は変更しない。
- 保存失敗は折りたたみの外に表示し、学習中も画面内に通知する。平常時の保存メッセージは省き、バックアップ・復元の結果は表示する。

## お気に入り

- 各問題のヘッダーに☆／★のネイティブボタンを置き、`aria-pressed`で登録状態を伝える。登録・解除は回答・答えの閲覧として記録しない。
- 固定の問題IDをキーとし、回答履歴とは独立した`architect-steel-favorites:v1:item:`プレフィックスでブラウザ内に保存する。問題改訂によってお気に入りを解除しない。端末間の同期や回答履歴バックアップへの同梱はしない。
- 一覧の「お気に入りのみ」はキーワード、導入層、復習などの条件とANDで組み合わせる。条件リセットは表示条件だけを戻し、お気に入り登録を消さない。
- お気に入りだけを表示する通常一覧で解除したカードは一覧から外し、他のカードの解説は閉じない。10問セットや前提確認中の登録・解除では、問題を移動・非表示にせず、セットの回答数も変えない。
- 他タブの変更は表示状態に取り込み、絞込み結果は次の明示的な絞込み操作で更新する。保存失敗時は登録済みと表示せず、折りたたみの外にエラーを通知する。

## 成績と追加確認

- 回答後はA／Bの丸アイコンの正解側を緑にし、不正解を選んだ場合は選択側を赤にする。今回の初回回答に対応させ、解き直し・再読み込み・翌日の新しい試行では元の色へ戻す。印刷には採点色を出さない。
- カード上の回答状況は未回答／回答済み／要復習／重点復習と、今回の正誤・答え確認後の区別だけを短く表示する。連続誤答数、復習解除までの日数、最終回答日時、旧版の扱いは「i」の補助情報へまとめる。保存失敗は引き続き折りたたみの外に表示する。
- 本体の未回答／要復習／重点／本日の回答件数と、小項目ごとの回答数を表示する。「習得率」「合格可能性」とは呼ばない。
- 本日の回答件数は主問題IDごとの重複なし件数。追加確認は含めない。
- 同日に答えや解説を見た後の回答は練習。独力の誤答・別日2回の独力正解による復習判定は従来仕様のまま。
- 追加確認6問は数値違い3問と、H断面の軸・部位、溶接記号の独自図3問。解説から任意に開ける。
- 追加確認は独立したID・改訂で記録し、常に追加練習として扱う。本体の回答数や復習解除を変更しない。履歴バックアップには本体と一緒に含む。
- 「学習計画の状態」は公開データ由来で個人履歴と異なるため、出典などと一緒に詳細条件へ置く。

## 改訂と安全性

- 本体の問題文・選択肢・正解・図・表示する三点の内容が変われば、そのカードのみ新版になる。旧履歴は削除・再採点せず保持し、新版を再確認する。
- UIの装飾や追加確認の追加だけでは本体の改訂を変えない。
- 保存セット内の改訂カードは新版へ更新し、該当する回答済みマークのみ外す。削除・対象範囲外のカードはセットから除く。問題の順序は維持し、再開先は最初の未回答とする。
- 保存失敗は画面に明示する。破損した保存セットや回答履歴は勝手に消去・上書きしない。閲覧と答えの開閉は可能な限り維持する。
- セットの途中位置は回答バックアップの対象外。回答の復元後は新しいセットを作れる。
