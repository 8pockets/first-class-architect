# 一級建築士学科の学習方法に転用できる学習科学の原則

調査日: 2026-08-02

## 結論

本質理解・未見問題への転移・長期保持を同時に狙うなら、学習の単位を次の循環にするのが最も妥当である。

> **範囲を絞ったインプット／解答例の理解 → 資料を閉じた想起 → 原理と条件の自己説明 → 表面的な条件を変えた問題への適用 → 根拠のあるフィードバック → 間隔を空けた再想起と混合練習**

「過去問を解いて、分からなければ読み直す」だけでは、同じ設問への再認と理解を区別しにくい。過去問は知識の入口・診断材料として使いつつ、**正誤を当てることではなく、根拠、成立条件、例外、条件変更後の結論を資料なしで生成すること**を主なアウトプットにするべきである。

以下の研究は、一級建築士試験そのものや日本の働く受験者を直接調べたものではない。したがって、30分の配分、復習日、5分の最低行動などは研究結果そのものではなく、エビデンスを現在の生活条件へ移した設計仮説であり、2週間の構造パイロットで検証する必要がある。

## 推奨する学習ループ

### 1. 新しい内容を扱う朝30分

これは研究で直接比較された「唯一の最適配分」ではなく、上の原則を現在の時間制約へ落とした検証案である。

1. **遅延想起（5分）**
   - 前日または数日前の内容について、資料を見ずに原理、成立条件、例外を記す。
   - 正誤問題なら、答えではなく根拠を先に言う。
2. **狭いインプット（7分）**
   - 新しい原理1つと代表例1つだけを読む。
   - 図・式・条文・現象の間の関係を探す。全文をきれいにノートへ写さない。
3. **閉じて自己説明（6分）**
   - `なぜそうなるか`、`どの条件が結論を変えるか`、`似た概念との差`を資料なしで説明する。
   - 説明できない箇所を、追加インプットの対象として印を付ける。
4. **変形した適用問題（8分）**
   - 過去問1問、または条件を1つ変えた派生問を解く。
   - 問題を見た瞬間に答えを思い出した場合は、条件反転・理由記述・誤選択肢の訂正に切り替える。
5. **根拠付きフィードバックと再生成（4分）**
   - 教材・解説と照合し、差の原因を1つ記録する。
   - 資料を閉じて、訂正した理由をもう一度説明する。

### 2. 昼休み・最低5分

- 昼休みは新規インプットではなく、朝に扱った内容を1問だけ資料なしで思い出す。
- 朝30分を確保できない日は、開始合図を保つために「前回の原理を1分で説明 → 1問判断 → 根拠確認」だけ行う。
- 5分実施は完全な学習量の代替ではなく、**再開可能性を保つための下限**とする。

### 3. 2週間パイロット中の復習配置

実務上の仮置きとして、新規学習日を0日目とし、**1日後、3〜4日後、7日後、14日後**に再想起する。各回は同じ設問を再生するだけでなく、次のいずれかに変える。

- 根拠を白紙から説明する。
- 成立条件を1つ変え、結論を予測する。
- 似た原理・規定との境界を説明する。
- 初見または自作の変形問題を解く。
- 数日後の失敗に応じ、次の間隔を短くする。安定して理由まで再現できれば広げる。

この日程自体の優位性は未検証である。重要なのは、同一セッション内の反復ではなく、忘却が生じうる間隔を空けた生成を複数回行うことにある。

## 「過去問を覚えただけ」を見抜くテスト

同じ過去問への正答は、理解の判定に使わない。次の4つを別々に測る。

1. **保持**: 3〜7日後、問題文なしで原理・条件・例外を説明できるか。
2. **近い転移**: 数値、向き、用途、構造形式などを1つ変えても判断できるか。
3. **識別**: 似た2つの規定・現象から、どちらを使うかと理由を選べるか。
4. **誤り訂正**: 誤った選択肢を、根拠を保ったまま正しい文へ直せるか。

採点は正誤だけでなく、少なくとも `結論`、`理由`、`効いている条件` の3点で行う。答えを覚えていても理由または条件を説明できなければ「未定着」と判定する。この採点方法は学習科学から直接得られた尺度ではなく、ユーザーが合意した本質理解の定義を操作可能にした設計案である。

## 避けるべき誤用

- **想起だけにする**: 基礎知識がなく何も生成できない状態では、短いインプットや解答例が必要である。
- **誤答を放置する**: 特に正誤・多肢選択では、誤選択肢の内容を学習してしまう可能性がある。根拠を確認して再生成する。
- **同じ過去問を高得点になるまで回す**: 問題固有の手掛かりを覚えた可能性を除外できない。遅延・変形・説明で測る。
- **全科目を無作為に混ぜる**: インターリーブは材料によっては無効または逆効果である。混同しやすい型の識別に限定する。
- **1回休んだら計画をリセットする**: 1回の欠席より、次の安定した合図で戻ることを優先する。
- **具体的な復習間隔を科学的な正解だとみなす**: 保持したい期間と内容によって適切な間隔は変わる。

## 研究から直接はいえないこと

- このループが2027年一級建築士学科の合格率をどれだけ上げるか。
- 朝30分が、本人の他の時間帯より学習効率に優れるか。朝は本人が最も安定して確保できると判断した生活上の選択である。
- 30分内の各工程の最適な分数。
- 構造で有効だった方法が、条文検索を含む法規、文章知識の多い施工、計画、環境・設備へそのまま移るか。
- 2週間で習慣が形成されるか。習慣形成期間には大きな個人差があり、2週間は学習ループの実行可能性を評価する期間と考えるべきである。
