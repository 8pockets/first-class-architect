# 構造から他科目へ展開する条件

決定日: 2026-08-05

根拠: [構造から他科目へ展開する条件を決める](https://github.com/8pockets/first-class-architect/issues/11)

## 決定

構造パイロットで採用された方法を、そのまま全科目へコピーしない。全科目で固定するのは、準備済みセットから始め、資料を閉じた想起、狭い入力、自分で生成する説明、初見の適用、根拠確認後の再生成、間隔再テストへ進む**共通学習核**だけとする。

計画、環境・設備、法規、施工では、入力単位、アウトプット形式、資料参照の扱い、転移問題の条件変更、混ぜる類似概念を**科目アダプタ**として事前に定義する。各科目は、共通学習核と科目アダプタを組み合わせた科目パイロットに合格してから科目内採用する。

この決定は他科目の学習開始を意味しない。実際の構造パイロットが評価可能になり、理解、転移、保持、継続の全基準を満たすことが、横展開を始める前提である。

## 年度依存事項

2026年8月5日時点で、公表済みの2027年試験受験要領は確認できない。2026年の公式案内では、学科試験は計画、環境・設備、法規、構造、施工の五科目で構成され、法規には法令集チェックの時間が設けられている。2027年の出題範囲、適用法令、使用できる法令集、持込条件は、2027年の公式受験要領が公表された時点で差し替える。

- [一級建築士試験「試験について」](https://www.jaeic.or.jp/shiken/1k/about-exam.html)
- [2026年一級建築士試験受験要領](https://www.jaeic.or.jp/.assets/jyukenyoryo-1k-2026.pdf)
- [公式の過去の試験問題等](https://www.jaeic.or.jp/shiken/1k/1k-mondai.html)

公式の過去問題も、実施時点の法令、規格、基準と現在の内容が一致しない場合がある。特に法規の診断問題は、年度と根拠法令を確認できない限り有効問題にしない。

## 横展開を始める条件

次をすべて満たすまで、最初の科目パイロットを開始しない。

1. 構造パイロットが最低証拠を満たして評価可能になっている
2. 構造パイロットが理解、転移、保持、継続の四基準をすべて満たし、方法採用になっている
3. 未完了の方法修正、判定保留、翌日再テストが残っていない
4. 対象科目について、一つの狭い題材、主教材、四つの判定単位、二つの保持対象を開始前に選んでいる
5. 科目アダプタと六つの有効な転移テスト枠を、結果を見る前に記録している
6. 朝30分を通常10回、最低8回確保できる14日間を選んでいる

構造で条件を満たさない場合は、構造の修正または別方法の設計を優先する。他科目を追加して証拠を増やしたことにしない。

## 全科目で変えない共通学習核

### 開始と時間の境界

- 平日の主学習は出勤前30分とし、30分で打ち切る
- 朝に声を出さず、すべて短い文字入力か粗い図で行う
- 開始時点で、対象範囲、想起課題、問題、TODOが答えを隠した状態で準備されている
- 30分できない日は5分の縮退学習を一件だけ行い、夜に埋め合わせない
- 欠席や中断後は、次の二回の予定機会以内に主学習または縮退学習へ戻る
- 通勤中は安全な状況だけを任意枠とし、操作を前提にしない

### 学習の順序

各科目とも、次の順序は変えない。

1. **遅延想起**: 資料を開く前に、前回までの対象を再生成する
2. **狭い入力**: 主教材の一単位だけを読む、見る、または参照する
3. **自力アウトプット**: 資料を閉じ、科目アダプタで定めた三点を自分で生成する
4. **診断・転移**: 同じ問題の再認ではなく、未見の条件変更に答える
5. **根拠確認と再生成**: 根拠との差分を確認し、資料を再び閉じて訂正版を作る

標準配分は、遅延想起5分、入力7分、アウトプット6分、診断・転移8分、根拠確認と再生成4分とする。科目アダプタで配分を変えてよいが、30分上限、想起を入力より先に行うこと、自力アウトプットをフィードバックより先に行うこと、五段階を削除しないことは変えない。変更配分はパイロット開始前に固定する。

### 証拠と道具の境界

- 過去問への一回の正解や得点率だけで習得としない
- 資料なしの初回回答と、根拠確認後の訂正版を分けて残す
- 1、3、7、条件付き10、14日後の間隔再テストを使う
- 誤答は主原因一つと観測差分一文にし、次の一件へ変換する
- 一度の修正では、最も上流の未達に関係する一変数だけを変える
- ChatGPTは対話コーチ、Codexは教材担当とし、どちらも正解根拠にしない
- NotebookLMは通常ループへ追加しない
- 問題文、解説全文、個人の詳細記録はGitHubへ置かない

## 科目アダプタで変えてよいもの

各科目パイロットの開始前に、次を一枚のアダプタとして固定する。

```text
科目:
題材と除外範囲:
主教材と版・基準日:
四つの判定単位:
二つの保持対象:
自力アウトプットの三点:
各段階で参照してよい資料:
六つの転移テスト型:
混ぜて識別する類似概念:
標準配分から変える時間:
問題無効にする条件:
```

変えてよいのは、入力の切り方、三点アウトプットの項目、参照資料の使用段階、条件変更の軸、類似概念の組合せ、30分内の配分である。準備なしの開始、答えの先取り、資料を見ながらの初回説明、同じ過去問の再答だけによる合格、夜の埋め合わせはアダプタにできない。

## 科目別の推奨アダプタ

### 計画

計画では、因果原理と名称・事例知識を同じ形式に押し込まない。

| 対象 | 狭い入力 | 自力アウトプット | 転移テスト |
|---|---|---|---|
| 計画原理 | 一つの用途、動線、寸法、行動特性 | 結論 / 利用者行動または計画意図 / 適用条件 | 用途、利用者、規模、敷地条件を変えて判断する |
| 名称・事例 | 一つの建築、都市、設計者、時代と比較対象一つ | 名称 / 固有の特徴 / 混同相手との識別点 | 類似作品、設計者、時代、特徴を入れ替えて識別する |

事例知識へ存在しない因果理由を作らない。単独の名称暗記ではなく、混同しやすい二〜三件から識別できることを転移とする。

### 環境・設備

一つの現象、式、図表、設備系統を単位とし、表現を変えても同じ関係を扱えるようにする。

- 自力アウトプット: **変化方向または量 / 因果連鎖または式 / 単位と成立条件**
- 条件変更: 入力変数の増減、境界条件、単位、グラフの軸、設備方式、建物用途
- 初見統合: 文章、簡図、グラフ、簡単な計算のうち二形式以上をまたぐ
- 混合: 名前が似た設備ではなく、同じ目的を異なる原理で実現する方式を二〜三種類だけ混ぜる

計算結果だけ、公式名だけ、グラフ形状の再認だけでは合格にしない。

### 法規

法規は、条文知識の想起と、本番形式の参照探索を分けて測る。2027年の公式条件が公表されるまでは、2026年の受験要領を暫定参照とし、最終アダプタを確定しない。

- 狭い入力: 一つの論点について、適用関係、参照経路、本文、例外を主教材と現行根拠で確認する
- 資料なしの自力アウトプット: **論点と適用条件 / 参照する法令・条文への経路 / 暫定結論と確認すべき例外**
- その後の参照探索: 使用予定の法令集で根拠へ到達し、**根拠箇所 / 最終結論 / 例外**を制限時間内に確定する
- 条件変更: 用途、規模、区域、面積、高さ、手続、例外条件を一つずつ変える
- 初見統合: 二つ以上の法令または本文と例外をたどるが、問題文だけで参照先を明示しない

資料なしで条文番号を丸暗記できても、参照経路を選べず根拠へ到達できなければ合格にしない。一方、法令集を使う段階はカンニング扱いにせず、本番課題の一部として時間と経路を記録する。古い過去問、改正反映を確認できない生成問題、根拠が一意でない問題は問題無効とする。

### 施工

一つの工種、作業順序、品質管理、安全管理、数値条件を現場状況と結び付ける。

- 自力アウトプット: **行う判断または手順 / 目的と防ぐ不具合 / 前後工程・現場条件・数値条件**
- 条件変更: 材料、天候、下地、施工順序、検査時点、不具合、担当主体、数値条件
- 初見統合: 工程の前後関係と品質・安全上の理由を同時に問う
- 混合: 同じ目的を持つ工法、混同しやすい検査時点、似た数値条件を二〜三種類だけ混ぜる

数値だけ、工法名だけ、語順だけを覚えた回答は合格にしない。実務経験と教材の記述が異なる場合は、試験で問われる条件を主教材で確認し、経験だけで正誤を上書きしない。

## 科目パイロットの共通評価

構造パイロットと同じく、理解、転移、保持、継続を別々に測る。構造の「四原理」は各科目の「四判定単位」と読み替える。

| 領域 | 科目パイロットの合格条件 |
|---|---|
| 理解 | 四単位のうち三単位以上で、科目アダプタの三点を根拠確認後に資料を閉じて正しく再生成 |
| 転移 | 有効な六問のうち四問以上を初回または翌日の別問題までに合格し、初見統合を一問以上合格 |
| 保持 | 事前指定した二単位が7日後と14日後の基準を満たし、少なくとも一単位は14日後の初回で合格 |
| 継続 | 予定機会の80%以上で実施し、主学習六回以上、30分超過一回以下、夜の埋め合わせと危険な通勤学習はゼロ |

法規だけは、資料なしの参照経路予測と、法令集を使った制限時間内の根拠確認の両方を満たして一問の合格とする。計画の名称・事例は「結論・理由・条件」ではなく「名称・固有特徴・識別点」の三点を使う。この違いは基準緩和ではなく、測る知識構造の違いである。

最低証拠、問題無効、判定保留、一変数修正、方法中止は、[2週間の構造パイロット検証基準を文書化したDraft PR](https://github.com/8pockets/first-class-architect/pull/22)と同じ判定順を使う。結果を見て合格条件を変えない。

## 段階的な展開順

複数科目を同時に始めない。次の順で、一つずつ結果を閉じてから進む。

1. **構造**: 現在のパイロットで共通学習核の候補を作る
2. **環境・設備**: 構造に比較的近い因果、図表、計算で近い横展開を試す
3. **法規**: 資料参照と経路選択を含む最も異なる課題で遠い横展開を試す
4. **施工**: 手順、現場条件、品質・安全の因果へ適応する
5. **計画**: 因果原理と名称・事例知識を分離して適応する

構造、環境・設備、法規の三科目で共通学習核を変えずに科目パイロットを通過した時点で、共通学習核を**横断確認**とする。ただし、施工と計画の科目アダプタまで採用されたことにはしない。施工と計画も、それぞれの科目パイロット通過後に科目内採用する。

## 失敗時の切り分け

1. 一科目の最初の未達は、その科目アダプタの最上流の一変数だけを修正する
2. 一度修正しても同じ基準が未達なら、その科目アダプタを中止し、別方式を設計する
3. 同じ共通学習核の要素が、異なる二科目で同じ失敗原因になった場合は、共通学習核の横展開を停止して再設計する
4. 睡眠、健康、仕事、家族時間、安全への即時中止条件は、科目の成績より優先する
5. 一科目の失敗だけで、合格済みの他科目アダプタや受験勉強全体を中止しない

共通学習核と科目アダプタを同時に変更しない。どちらが結果へ影響したか分からなくなるため、修正後の検証では一つだけを変える。

## 境界シナリオ

| 状況 | 判断 |
|---|---|
| 構造で理解と転移は通ったが14日保持が未判定 | 横展開しない。構造の結果を閉じる |
| 環境・設備で式は解けるが、グラフへ表現が変わると0/2 | 環境・設備アダプタの転移問題を一変数修正する |
| 法規で結論を暗記しているが、法令集で根拠へ到達できない | 法規の転移未達。科目内採用しない |
| 法規問題の根拠が法改正前の条文だった | 問題無効。学習者の誤答にしない |
| 計画の事例問題で因果理由を説明できない | 名称・固有特徴・識別点で測り直す。存在しない因果を要求しない |
| 構造、環境・設備、法規は通過した | 共通学習核を横断確認。施工と計画はまだ未採用 |
| 異なる二科目で30分超過が同じ原因で続く | 科目追加を止め、共通学習核の時間配分を再設計する |
| 一科目のため夜の家族時間を恒常的に使う | その運用を即時中止。合格条件を下げて継続しない |

## 残す記録

個々の問題文、教材本文、毎日の詳細な回答はローカルに保つ。GitHubには次だけを残す。

- 使用した科目アダプタの版
- 理解、転移、保持、継続の集計
- 問題無効数と主な理由
- 科目内採用、修正、保留、中止の判断
- 共通学習核を変更したか、変更していないか

この集計により、科目の難しさ、作問不備、共通学習核の失敗を混同せず、次の一変数を決める。
