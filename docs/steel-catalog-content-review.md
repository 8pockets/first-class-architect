# 鉄骨構造台帳の内容レビュー

監査日: 2026-08-14

対象:

- ローカル教材 `2026_構造_文章問題.pdf` のPDF上P158〜P215
- `data/principles/steel/` の鉄骨構造台帳
- GitHub Pagesへ公開される `source_checked` 項目

このレビューは勉強方法ではなく、台帳の分類、粒度、出典、公開範囲が教材の内容を適切に表しているかを扱う。

## 結論

公開中の116件は、教材の該当箇所へ遡れる安全な部分集合になっている。一方で、台帳全体を見渡す分類と、教材全範囲を代表する公開カタログとしては未完成である。最大の問題は次の四点である。

1. `本試験知識（横断）` が48件、うち公開34件を抱え、分野ではなく出現場所でまとめられている
2. 215件のうち97件が一律に `教材に記載なし` となり、主張の根拠不足と説明の不足を区別できない
3. 原理は84件中70件を公開できている一方、規定は79件中25件、識別は52件中21件に留まり、公開内容が因果説明へ偏っている
4. 一枚に複数判断を含む項目と、同じ判断を重ねた項目が残り、検索・復習・出典確認の単位が揃っていない

したがって、`本試験知識（横断）` の小分けだけではなく、全215件を同じ分類規則で振り直す。教材内の保管場所は出典情報として残し、Pagesの分類には使わない。

## 項目の粒度

一項目は、問題で一つの判断を求め、本文でその判断の根拠と境界を説明できる単位にする。監査で見つかった六つの複合項目は、それぞれ二項目へ分割する。

- 箱形柱・H形梁の剛接合: フランジとウェブの応力分担 / 溶接詳細
- ブレースの水平力負担: 水平力を軸力へ変える機構 / 鉛直・水平ブレース面の役割
- ブレース架構の終局耐力: 柱とブレースの総和 / X形ブレースの引張・圧縮寄与
- 細長比と履歴: ブレースの細長比による履歴 / ラーメン架構の履歴
- 工場接合と現場継手: 位置と製作場所 / 現場継手の方法と理由
- 根巻き柱脚: 曲げモーメントの分担 / せん断力の関係

重複は、圧縮材の無座屈耐力、圧縮ブレースの座屈、高強度鋼梁の断面縮小とたわみ、現場継手の四群で統合する。分割後の子項目は出典と問題を再確認し、統合項目は失われる条件がないことを確認してから公開する。

再確認の結果、筋かい付き骨組について「柱の水平せん断耐力と筋かいの水平せん断耐力を合算する」とした子項目は、教材P170及びP200〜P204で独立した根拠を確認できなかった。この項目は問題を外して `source_gap` へ戻した。これにより、原子化後の総数は216件、公開は116件となる。

## 出典の判定を二軸に分ける

従来の `source_checked` は「教材内で確認した」と「内容が十分に説明されている」を一つにまとめていた。今後は少なくとも次を別々に記録する。

- 主張の根拠: 教材、法令、告示、JIS、日本建築学会資料、国の標準仕様書のどれで確認したか
- 説明の完全性: 理由と条件が完全、部分的、不足、未監査のどれか
- 出典が支える範囲: 主張、説明、条件のどこまでか

外部出典を追加しても、出典が支えていない理由や例外を補完しない。URLは検索結果ではなく、法令本文、告示本文、規格・指針の正式な公開ページを記録する。

今回の確認で、次の一次資料を出典候補として特定した。

- [建築基準法施行令](https://laws.e-gov.go.jp/law/325CO0000000338/20250401_506CO0000000001): 溶接継目の許容応力度
- [平成12年建設省告示第2464号](https://www.mlit.go.jp/notice/noticedata/pdf/201703/00006510.pdf): 異なる種類又は品質の鋼材を溶接する場合の基準強度
- [公共建築工事標準仕様書（建築工事編）令和7年版](https://www.mlit.go.jp/gobuild/content/001888816.pdf): 耐火被覆の工法区分、材料、施工、試験
- [平成12年建設省告示第1433号](https://www.mlit.go.jp/notice/noticedata/pdf/201703/00006487.pdf): 耐火性能検証で扱う可燃物の発熱量

これらを見つけたこと自体は公開条件を満たさない。各カードの主張、説明、条件へ一対一で対応付けた後にのみ `source_checked` へ昇格する。

## 表示形式

内容の種類に合わせて三点の見出しを変える。

| 種類 | 第1欄 | 第2欄 | 第3欄 |
|---|---|---|---|
| 原理 | 結論 | 理由 | 結論を左右する条件 |
| 規定 | 規定 | 適用範囲 | 数値・例外 |
| 識別 | 定義 | 識別条件 | 混同注意 |

Pagesは内容を読む正本であり、回答を保存する試験画面にはしない。三点と正解は一つの開示要素へまとめ、初期状態を閉じたうえで、初回学習前にも必要なときに開いて読めるようにする。別に出題する診断・変形問題の答えを先に見せない境界は維持する。CLIと準備済み学習セットでは、従来どおり正解と三点を最初から表示する。

既存の `reason` を規定の「適用範囲」、識別の「識別条件」と機械的に読み替えてはならない。公開する規定・識別には型別の表示内容を明示し、不足時は一般ラベルへ黙ってフォールバックせず公開生成を失敗させる。

## ID、問題番号、旧リンク

- 現在の `S-K6-*` は不変の内部キーとして残し、既存の学習履歴を結び付け続ける
- 公開コードは `structure.steel.<意味を表すslug>` とし、分類番号、並び順、ページ、問題番号を埋め込まない
- 発行済みの旧キーと旧URLは無期限の別名として解決する
- 分割された旧キーは、後世代で移行先が一件へ収束しても一方へ黙って転送せず、分割来歴の索引として残す
- 一度も公開していない項目を退役しても、その内部キー、公開コード候補、別名をPagesへ新たに出さない
- `K6-R1 Q001`〜`Q116` は過去版として凍結し、再編集しない
- 新しい学習順は `K6-R2` として発行し、前提項目を先に置く
- 印刷の通し番号と版付き問題番号を分け、表示中の絞込みで問題番号を変えない

## 公開範囲を増やす順序

第7群「耐火・特殊荷重」8件で、暫定三点、検索語、固定URL、確認済み台帳との分離が機能するかを `/research/` で検証し、初回パイロットを完了した。8件の一次資料調査と未解決点は、[耐火・特殊荷重8項目の根拠監査](./research/steel-fire-special-source-review.md)に残す。

パイロット確認後、未確認100件を `/research/` へ広げ、確認済み116件にも閉じた参考検索を加える。全216件に一次資料優先・解説向けの検索語を設定するが、問題又はcoverage tierは追加せず、検索結果だけで `source_checked` へ昇格しない。

正式な根拠確認は、本試験知識表の主行のうち公開カードがない次の30コードを優先する。

`05162`, `06161`, `23302`, `19251`, `05164`, `23171`, `06164`, `28151`, `25193`, `05161`, `18182`, `23153`, `05151`, `02172`, `20165`, `23172`, `03161`, `01173`, `24163`, `07263`, `18184`, `23164`, `29164`, `20181`, `24162`, `27171`, `24184`, `18173`, `19154`, `18165`

次に残る `source_gap` を、規定、識別、原理の順で確認する。件数を増やすこと自体を目標にせず、主張と三点を正式資料で支えられる項目だけを公開する。

高温時の鋼材強度について教材内にある二つの温度記述は、同じ閾値として統合しない。耐火被覆の工法分類を確認できても、工期、価格、割れ、使用場所などの比較が同じ出典で支えられなければ、その比較までは公開しない。

## 継続検証

CIでは次を不変条件として検査する。

- 有効項目が7群・37小項目へ重複なく一度ずつ所属する
- 内部キーと公開コードが一意で、旧別名を中央の解決器で扱える
- 発行済みの公開コード、旧別名、移行経路、旧セクションを削除又は付け替えていない
- 前提関係に欠落と循環がなく、公開項目の前提も公開済みである
- 表示順で全前提が依存先より先に現れる
- 過去の問題版を変更せず、現行版が公開項目を一度ずつ含む
- 内容、分類、前提、表示順、識別子、移行経路の監査ハッシュを別々に検証する
- 公開HTMLに教材本文、個人の回答、詳細な学習履歴を含めない
